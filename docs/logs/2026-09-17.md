## 결정

- IDE는 서버에 붙지 않는다. 실행 경로는 항상 IDE → Local Agent → Server.
- Agent↔Server는 지금 gRPC만. WebSocket Adapter는 같은 `transport` 인터페이스에 나중에 붙일 수 있게만 둔다.
- 승인만으로 apply 하지 않는다. actual diff는 Local Agent가 만든다.
- 이 PC에서 onCode HTTP는 18080. 8080은 HRE Keycloak. gRPC는 9443.
- VSIX는 `npm run package`로만 만든다. 아이콘은 `media/icon.png`.
- protobuf `sun.misc.Unsafe` 로그는 JDK 25 경고이며 기동 실패가 아니다.
