## 결정 사항

- JSON이 논리 프로토콜. protobuf는 전송 어댑터.
- JSON Envelope는 `payload` 객체. proto는 typed payload + `arguments_json` / `result_json`.
- proto JSON 이름은 snake_case `json_name`.
- Envelope에 SPEC-01 예시에는 없는 `workspace_id`를 PHASE_00 요구대로 선택 필드로 넣음.
- `protoc` 코드젠은 Phase 0 필수에서 제외. `.proto` + 필드 매핑 테스트로 계약 고정.

## 계획 대비 차이

계획 체크리스트는 모두 완료. `protoc` 미사용은 계획 리스크대로 처리. 오전에 문서/규칙 정리까지 한 뒤에 Phase 0 코드를 넣음.
